# V12.3.2 — Correções da integração Supabase Auth

- Backend recebe SUPABASE_URL e SUPABASE_PUBLISHABLE_KEY no docker-compose.
- Auth do frontend e backend deve usar o mesmo projeto Supabase RFN.
- Perfil e papel admin são consultados no Supabase REST com o JWT do usuário e sob RLS.
- DATABASE_URL continua apontando para o PostgreSQL operacional do RFN; os dados locais não são movidos nesta correção.
- Não configure a secret key do Supabase no frontend.
