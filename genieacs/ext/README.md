# Extensões GenieACS

Aqui ficarão as extensões específicas de fabricante/modelo.

Estratégia planejada:
- ZTE F6201B
- ZTE F6600P
- C-Data FD511G-X-F670
- C-Data FD514GS3-R850
- Intelbras
- TP-Link
- Mercusys

Não devemos inventar nomes de parâmetros. Primeiro coletamos o Parameter Tree real do firmware através do GenieACS e então criamos os provisions.
