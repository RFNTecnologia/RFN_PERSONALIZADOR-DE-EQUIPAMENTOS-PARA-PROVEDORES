# RFN V12.3.6 — Ativação controlada de PPPoE

Patch sobre RFN V12.3.5. Contém apenas `frontend/app.js`.

## Mudanças
- Adiciona seleção explícita entre `Laboratório / manutenção` e `Ativação de cliente final`.
- O modo cliente exige confirmação de que a conta PPPoE definitiva está criada/validada no MikroTik e mostra uma confirmação final com o usuário anterior/proposto (nunca exibe senhas).
- Mantém validação de parâmetros do cache marcados como graváveis.
- Mantém a lista de parâmetros atual: PPPoE, Wi-Fi 2,4/5 GHz; não altera VLAN, LAN, ACS ou acesso remoto.
- A UI esclarece que aceitação do ACS não significa aplicação; exige verificar próximo Inform e estado real do CPE.

## Instalação
1. Faça cópia de `frontend/app.js`.
2. Extraia o ZIP na raiz `RFN_Personalizar-roteadores`.
3. Substitua somente `frontend/app.js`.
4. Abra o painel com Ctrl+F5; não é necessário reconstruir containers se o frontend é servido por volume do Nginx.

## Limites
Esta é uma etapa explícita de interface/confirmação, não uma implementação completa de gestão de clientes/ordens de serviço nem uma auditoria persistida no backend. O endpoint existente envia `setParameterValues` ao GenieACS. A aplicação deve ser verificada lendo o CPE após Inform. Ainda não automatiza o ISP Preset/Agile Config e não pretende tornar o equipamento imune a reset nem impedir tecnicamente toda forma de bypass.
