# V12.3 — Provisionamento RESIDENCIAL MR60X

- A aba Provisionamento agora apresenta um fluxo direto para o perfil RESIDENCIAL do MERCUSYS MR60X.
- Campos da tela: usuário/senha PPPoE, SSID 2,4 GHz, SSID 5 GHz e senha Wi-Fi.
- Usa caminhos identificados no catálogo do MR60X para PPPoE, MTU/MRU e Wi-Fi; remove a necessidade de digitar os caminhos manualmente.
- Envia tarefa `setParameterValues` pela API existente e informa que a tarefa precisa ser confirmada pelo próximo Inform do CPE.
- Não altera VLAN automaticamente.
- Senhas são campos de entrada e não são incluídas na mensagem de status.
- Atualizado o parâmetro de cache do JavaScript para forçar o navegador a carregar a interface nova.

## Validação realizada
- `node --check frontend/app.js`
- `node --check backend/server.js`

A validação de sintaxe não substitui a confirmação de aplicação pelo MR60X em ambiente real. O provisionamento só deve ser considerado concluído após o retorno do CPE/GenieACS.
