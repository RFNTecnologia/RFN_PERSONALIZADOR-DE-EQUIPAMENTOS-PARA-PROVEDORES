# RFN V12.3.5 — Resumo de estado operacional do CPE (patch frontend)

## O que muda
- Adiciona um resumo fixo no modal de cada equipamento: link físico WAN, sessão PPPoE, IP WAN, usuário PPPoE e último Inform.
- Atualiza o resumo quando o técnico abre ou troca a aba do equipamento.
- Inclui “Recarregar leitura”, que relê o cache atual do GenieACS. O botão deixa explícito que isso não solicita, por si só, novo contato do CPE.
- Reconhece os caminhos TR-181 usados pelo MR60X e alguns caminhos comuns TR-098 como fallback.
- Não cria tarefa de escrita, não altera WAN/PPPoE/Wi-Fi, VLAN, LAN, credenciais ou ACS.

## Instalação
1. Faça backup de `frontend/app.js`.
2. Extraia o ZIP na raiz de `RFN_Personalizar-roteadores`.
3. Substitua somente `frontend/app.js`.
4. Atualize a interface com `Ctrl+F5`, abra o equipamento e confira o cartão “Estado operacional”.

## Como interpretar
- “Recarregar leitura” consulta novamente a API do RFN, que lê os valores atualmente guardados em cache no GenieACS.
- “Atualizar do CPE” solicita um novo contato/refresh; depois do próximo Inform, use “Recarregar leitura” para consultar o cache atualizado.
- “Connected” e um IP WAN válido são evidências de sessão reportada pelo CPE; o painel não presume sucesso apenas porque uma tarefa foi aceita.
- Os dados continuam sujeitos ao modelo, firmware e à atualização de parâmetros coletados no ACS.
